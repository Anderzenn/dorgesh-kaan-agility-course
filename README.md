# Dorgesh-Kaan Agility Course (Helper)

* Adds a movable widget that tells you which items Turgall requested
* Highlights the requested items from Turgall from the boilers
* Highlights the correct ground route to the generator:
  * Before you've picked up an item, both possible routes are shown (the grapple route only if you have a crossbow + mith grapple equipped)
  * Once you're carrying an item, only the correct route back is shown
* Won't highlight or let you select a delicate item (capacitor/fuse/meter) unless you have a crossbow and mith grapple equipped, since the grapple route can't be completed without one
* Shows which route (agility or grapple) to take in the info panel
* Optionally highlights Turgall (NPC)
* Lets you know if you have a spanner or not
* Widgets are removed from the screen when you're not in the area
* Highlight colours and outline stroke width are configurable

If you find any bugs or have any suggestions, please submit an issue on [GitHub](https://github.com/Anderzenn/dorgesh-kaan-agility-course/issues)
